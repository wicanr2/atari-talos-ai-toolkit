## 狀態模型

- `D0`–`D7`、`A0`–`A6` 為 32-bit；USP、SSP 與 PC 保留 32-bit CPU 狀態。
- 外部 bus address 固定遮成 24-bit。
- SR 的 S bit 是 `0x2000`；program read 的 function code 在 user mode 為 2、
  supervisor mode 為 6。
- 預取佇列保存兩個 word。語料的 `PC` 是下一次預取的 bus address；正在執行的 opcode
  位於 `prefetch[0]`，`prefetch[1]` 是下一個已取 word。

## NOP（`0x4e71`）

執行一條 NOP：

1. 不改變 D、A、USP、SSP 或 SR。
2. `prefetch[0] = old prefetch[1]`。
3. 從 `old PC & 0x00ffffff` 讀一個 big-endian word，寫入 `prefetch[1]`。
4. `PC = old PC + 2`。
5. 總長 4 clocks；第 4 clock 留下一筆 word read，UDS/LDS 皆為 1，資料是讀到的 word。
