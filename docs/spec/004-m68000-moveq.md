# 004 — Motorola 68000 MOVEQ

狀態：**READY**（2026-09-05）。

## 證據與範圍

- 使用 spec 003 固定的 `SingleStepTests/m68000` commit 與 MAME microcoded core oracle。
- 語料檔為 `MOVE.q.json.bin`，固定分母 2,500 筆。
- 本規格只涵蓋 `MOVEQ #<8-bit>,Dn`，opcode 形狀 `0111 ddd0 iiiiiiii`。

## 行為

1. 立即數作 8-bit two's-complement 符號延伸成 32-bit，整個覆寫指定 Dn。
2. X 不變；N 依 32-bit 結果 bit 31；Z 依結果是否為 0；V、C 清為 0。
3. A0–A6、其他 Dn、USP、SSP 不變。
4. 預取、PC 與 4-clock program word read 與 spec 003 的 NOP 相同。
5. 不寫 RAM。

## 驗收

逐筆比較 2,500 筆完整狀態、RAM、總 clock 與 bus transaction。只有全部通過才能把
MOVEQ 標為 CONFORMED。
