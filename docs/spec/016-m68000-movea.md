# 016 — Motorola 68000 MOVEA.W／MOVEA.L

狀態：**CONFORMED**（2026-09-05）。

## 範圍與輸入

本規格涵蓋 `MOVEA.W <source>,An` 與 `MOVEA.L <source>,An` 的全部合法 data source
定址模式及 A0–A7 目的暫存器。輸入為 spec 003 固定的 `SingleStepTests/m68000`
commit `64b253116a3de04aaac4346c43680960dc9b67e5`：

- `MOVEA.w.json.bin`：正常 1,658、source read address error 842，共 2,500。
- `MOVEA.l.json.bin`：正常 1,655、source read address error 845，共 2,500。

排除一般 MOVE、MOVEM、MOVEP、bus error 及 exception handler 自身再 fault。

## 證據與等級

- **已確認（平台規格）**：Motorola／NXP《M68000 Family Programmer's Reference
  Manual》4-119～4-120；word source 先符號延伸至 32 bits，long source 原值寫入 An，
  condition codes 不受影響。
- 官方 PDF SHA-256：
  `06e4864b78da0e815054cead9326b7ec9914661f240fd39a455f2061ff47c4e8`。
- **已確認（固定單步實驗）**：兩份語料逐筆提供完整 CPU state、RAM、clock 與 bus
  transaction；1,687 筆 odd source 另含 vector 3 的 14-byte frame。

## typed 行為

1. `MOVEA.W` 取 16-bit source，依 bit 15 符號延伸成 32 bits；`MOVEA.L` 取完整
   32-bit source。結果覆寫目的 An；A7 依當時 S bit 寫 USP／SSP。
2. 正常與來源 fault 都不因 MOVEA 更新 CCR。source EA、program／data FC、alignment、
   extension、prefetch、An predecrement／postincrement 副作用及 source address-error
   全部沿用已 CONFORMED 的 spec 014／015。
3. 正常 clocks 為 `4 + sourceCost`。word cost：direct 0、mode 2／3 為 4、mode 4 為 6、
   d16／abs.w／PC-d16 為 8、indexed／PC-indexed 為 10、abs.l 為 12、immediate 為 4。
   long cost：direct 0、mode 2／3 為 8、mode 4 為 10、d16／abs.w／PC-d16 為 12、
   indexed／PC-indexed 為 14、abs.l 為 16、immediate 為 8。
4. odd source 在讀取任何 operand word 前產生 `re`；SSW、saved PC、clock、frame、vector 3
   與 handler prefetch 分別沿用 word／long source 規格，不寫目的 An。

## 影響、驗收與停止線

- 只新增 MOVEA decode 與 An destination，不改控制協定、Atari 素材或權利邊界。
- 逐筆比較兩份語料共 5,000 筆完整 state、RAM、clock、bus 與 exception frame；既有
  37,500 筆不得回歸。
- 兩種寬度及正常／fault 固定分母全部通過才能升為 **CONFORMED**。
- 2026-09-05 驗收結果：MOVEA.W 正常 1,658／1,658、`re` 842／842；MOVEA.L
  正常 1,655／1,655、`re` 845／845，合計 5,000／5,000。全套外部單步語料累計
  42,500 筆全數通過。
