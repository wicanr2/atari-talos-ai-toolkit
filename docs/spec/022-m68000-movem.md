# 022 — Motorola 68000 MOVEM

狀態：**CONFORMED**（2026-09-05）。

## 範圍與輸入

本規格涵蓋 `MOVEM.W/L <register-list>,<ea>` 與
`MOVEM.W/L <ea>,<register-list>`。輸入為 spec 003 固定的
`SingleStepTests/m68000` commit `64b253116a3de04aaac4346c43680960dc9b67e5`：

- `MOVEM.w.json.bin`：2,500 筆。
- `MOVEM.l.json.bin`：2,500 筆。

排除 bus error、例外處理器自身再次 fault 及 68010 以後處理器差異；不合法方向／EA
組合維持失敗即關閉。

## typed 行為

1. register-to-memory 一般模式依 D0..D7、A0..A7 mask 順序傳送；predecrement 使用反向
   mask 與 A7..A0、D7..D0 順序。word 寫低 16 bits，long 依 big-endian word 次序提交。
2. memory-to-register 依正常 mask 順序載入；word 符號延伸為 32 bits。postincrement
   只在整批完成後提交最終地址，因此 EA register 同時在清單內時仍以最終地址為準。
3. memory-to-register 完成實際清單後另做一次 word 虛讀，再做 program prefetch；
   PC-relative operand 與虛讀都使用 program FC。
4. word／long 的 EA、extension、alignment、active A7 與 vector-3 frame沿用既有已驗證
   管線。predecrement long 的第一個微操作是 `An-2` low-word write，odd fault 以該地址
   建 frame，且不提交 An。

## 失敗模式、影響與驗收

- 不合法方向／EA、未實作 opcode 與 bus backend error 必須回傳錯誤，不得冒充成功。
- 不改 CCR、JSONL 控制協定、Atari 素材、存檔或權利邊界。
- 兩份語料共 5,000 筆逐筆比較完整 state、RAM、clock、bus 與 exception frame；既有
  77,500 筆不得回歸。
- 2026-09-05 驗收結果：5,000／5,000 全數通過；全套外部單步語料累計
  82,500 筆全數通過。
