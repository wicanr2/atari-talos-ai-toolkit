# 025 — Motorola 68000 TST

狀態：**CONFORMED**（2026-09-05）。

## 範圍與輸入

本規格涵蓋 MC68000 的 `TST.B/W/L <ea>`。輸入為 spec 003 固定的
`SingleStepTests/m68000` commit `64b253116a3de04aaac4346c43680960dc9b67e5`：

- `TST.b.json.bin`：2,500 筆。
- `TST.w.json.bin`：2,500 筆。
- `TST.l.json.bin`：2,500 筆。

排除 MC68020 才允許的 address-register direct、TAS、bus error 及例外處理器自身再次
fault；不合法 EA 維持失敗即關閉。

## 證據與等級

- **已確認（平台規格）**：Motorola／NXP《M68000 Family Programmer's Reference
  Manual》的 TST 定義；讀取 operand、不寫回，依寬度更新 N／Z、清 V／C、保留 X。
- 官方 PDF SHA-256：
  `06e4864b78da0e815054cead9326b7ec9914661f240fd39a455f2061ff47c4e8`。
- **已確認（固定單步實驗）**：三份語料逐筆提供完整 CPU state、RAM、clock 與 bus
  transaction；word／long odd operand 涵蓋 vector 3 的 14-byte frame。
- **已確認（Dungeon Master 使用範圍）**：ReDMCSB DM12EN 產生組語中，未加寬度的
  TST.W 271 次、TST.B 194 次、TST.L 5 次，合計 470 個靜態使用點。這只用於實作
  優先序，不等同執行期頻率。31 份 `.S` 逐檔 SHA-256 清單的 SHA-256 為
  `607feb2bc104af411d13e9909d9c57ffff626c3ef8737ec5cd765b22a7dafd46`。

## typed 行為

1. 讀取 Dn 或合法 memory data EA，但不寫回 operand；窄寬度只檢查對應低位。
2. 結果符號位設定 N，零值設定 Z；V、C 固定清除，X 保留。
3. byte／word／long 的 EA、FC、extension、alignment、postincrement／predecrement、
   program prefetch、clocks 與 vector-3 frame 沿用已逐筆驗證的 source-read 路徑。

## 失敗模式、影響與驗收

- An direct、PC-relative、immediate、TAS、未實作 opcode 與 bus backend error 必須
  回傳錯誤，不得冒充成功。
- 不改 JSONL 控制協定、Atari 素材、存檔或權利邊界。
- 三份語料共 7,500 筆逐筆比較完整 state、RAM、clock、bus 與 exception frame；既有
  85,000 筆不得回歸。
- 2026-09-05 驗收結果：7,500／7,500 全數通過；全套外部單步語料累計
  92,500 筆全數通過。
