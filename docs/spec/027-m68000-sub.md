# 027 — Motorola 68000 SUB／SUBI／SUBQ

狀態：**CONFORMED**（2026-09-05）。

## 範圍與輸入

本規格涵蓋 MC68000 的 `SUB.B/W/L <ea>,Dn`、`SUB.B/W/L Dn,<ea>`、
`SUBI.B/W/L #<data>,<ea>` 與 `SUBQ.B/W/L #<data>,<ea>`。輸入為 spec 003 固定的
`SingleStepTests/m68000` commit `64b253116a3de04aaac4346c43680960dc9b67e5`：

- `SUB.b.json.bin`：2,500 筆。
- `SUB.w.json.bin`：2,500 筆。
- `SUB.l.json.bin`：2,500 筆。

SUBA、SUBX 不在本切片；不合法 EA 及未實作編碼維持失敗即關閉。

  Manual》的 SUB／SUBI／SUBQ 定義。結果為 destination 減 source；依寬度更新
  X／N／Z／V／C，其中 X 與 C 同為 borrow。
- 官方 PDF SHA-256：
  `06e4864b78da0e815054cead9326b7ec9914661f240fd39a455f2061ff47c4e8`。

  bus transaction 與 address-error frame。固定分母為一般 SUB 4,608 筆、SUBI

## typed 行為

1. 一般 SUB 支援合法 data EA 至 Dn，以及 Dn 至可修改 memory EA；SUBI 先讀取
   immediate；SUBQ 的三位 immediate 值 `0` 解為 `8`。
2. byte／word 目的 Dn 只覆寫低 8／16 位；long 覆寫全部 32 位。結果依寬度更新
   X／N／Z／V／C；borrow 同時設定 X 與 C。
3. SUBQ 寫 An 時只允許 word／long，作 32-bit 減法且不改 CCR。
4. 記憶體目的端採 operand read → 最後一次 program prefetch → operand write；long
   寫回先 low word、再 high word。EA、FC、alignment、register side effect、clock 與
   vector-3 frame 應逐筆符合固定語料。

## 失敗模式、影響與驗收

- SUB／SUBI 的 An direct destination、SUBQ.B to An、PC-relative／immediate memory
  destination、SUBA、SUBX、未實作 opcode 與 bus backend error 必須回傳錯誤。
- 不改 JSONL 控制協定、Atari 素材、存檔或權利邊界。
- 三份語料共 7,500 筆逐筆比較完整 state、RAM、clock、bus 與 exception frame；
  既有 100,000 筆不得回歸。
- 2026-09-05 驗收結果：7,500／7,500 全數通過；全套外部單步語料累計
  107,500 筆全數通過。
