# 028 — Motorola 68000 ASL

狀態：**CONFORMED**（2026-09-05）。

## 範圍與輸入

本規格涵蓋 MC68000 的暫存器型 `ASL.B/W/L #<count>,Dn`、
`ASL.B/W/L Dn,Dn`，以及記憶體型 `ASL.W <ea>`。輸入為 spec 003 固定的
`SingleStepTests/m68000` commit `64b253116a3de04aaac4346c43680960dc9b67e5`：

- `ASL.b.json.bin`：2,500 筆。
- `ASL.w.json.bin`：2,500 筆。
- `ASL.l.json.bin`：2,500 筆。

ASR、LSL、LSR、ROXL／ROXR、ROL／ROR 與 MC68020 memory multi-bit encoding 不在
本切片；不合法 EA 及未實作編碼維持失敗即關閉。

## 證據與等級

- **已確認（平台規格）**：Motorola／NXP《M68000 Family Programmer's Reference
  Manual》的 ASL 定義。暫存器 count 可由三位立即值（0 代表 8）或資料暫存器低
  6 位提供；記憶體型固定 word、位移一位。
- 官方 PDF SHA-256：
  `06e4864b78da0e815054cead9326b7ec9914661f240fd39a455f2061ff47c4e8`。
- **已確認（固定單步實驗）**：三份固定語料逐筆提供完整 CPU state、RAM、clock、
  bus transaction 與 address-error frame，作為實作後同狀態驗收 oracle。
- **已確認（Dungeon Master 使用範圍）**：ReDMCSB DM12EN 產生組語中，ASL.W
  257 次、ASL.L 547 次，合計 804 個靜態使用點。這只用於實作優先序，不等同
  執行期頻率。31 份 `.S` 逐檔 SHA-256 清單的 SHA-256 為
  `607feb2bc104af411d13e9909d9c57ffff626c3ef8737ec5cd765b22a7dafd46`。

## typed 行為

1. 每次左移把零送入最低位，最高位送入 C；count 非零時 X 等於最後移出的位元，
   count 為零時 C 清除而 X 保留。
2. 結果依寬度設定 N／Z；只要位移過程中符號位曾改變，V 即設定。
3. 暫存器 count 只取來源 Dn 低 6 位；byte／word 目的只覆寫 Dn 對應低位。
4. 記憶體型只允許可修改 memory EA，採 word operand read → 最後一次 program
   prefetch → word write；EA、FC、alignment、side effect、clock 與 vector-3 frame
   必須逐筆符合固定語料。

## 失敗模式、影響與驗收

- An direct、PC-relative／immediate memory destination、非 word 記憶體型、其他 shift／
  rotate、未實作 opcode 與 bus backend error 必須回傳錯誤。
- 不改 JSONL 控制協定、Atari 素材、存檔或權利邊界。
- 三份語料共 7,500 筆逐筆比較完整 state、RAM、clock、bus 與 exception frame；
  既有 107,500 筆不得回歸。
- 2026-09-05 驗收結果：7,500／7,500 全數通過；全套外部單步語料累計
  115,000 筆全數通過。
