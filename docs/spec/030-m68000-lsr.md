# 030 — Motorola 68000 LSR

狀態：**CONFORMED**（2026-09-05）。

## 範圍與輸入

涵蓋 MC68000 暫存器型 `LSR.B/W/L #<count>,Dn`、`LSR.B/W/L Dn,Dn`，以及
固定一位的記憶體型 `LSR.W <ea>`。驗收輸入為 spec 003 固定的
`SingleStepTests/m68000` commit `64b253116a3de04aaac4346c43680960dc9b67e5`：
`LSR.b/w/l.json.bin` 各 2,500 筆，共 7,500 筆。

LSL、ASL、ASR、rotate 與後代 CPU 擴充不在本規格；不合法 EA 失敗即關閉。

## 證據與 typed 行為

- **已確認（平台規格）**：Motorola／NXP《M68000 Family Programmer's Reference
  Manual》；官方 PDF SHA-256 為
  `06e4864b78da0e815054cead9326b7ec9914661f240fd39a455f2061ff47c4e8`。
- 暫存器 count 來自三位立即值（0 代表 8）或來源 Dn 低六位；記憶體型固定 word
  且只移一位。
- 每次右移把零送入最高位，最低位送入 C；count 非零時 X 等於最後移出的位元，
  count 為零時 C 清除且 X 保留。結果設定 N／Z，V 固定清除。
- 暫存器 byte／word 只覆寫 Dn 對應低位；clock 隨實際 count 增加。
- 記憶體型採 word read → final program prefetch → word write，alignment、FC、EA
  side effect 與 vector-3 frame 必須逐筆符合固定語料。
- **已確認（DM 使用範圍）**：DM12EN 產生組語中 LSR.W 593、LSR.B 4、LSR.L 8，
  合計 605 個靜態使用點；31 份 `.S` 雜湊清單 SHA-256 為
  `607feb2bc104af411d13e9909d9c57ffff626c3ef8737ec5cd765b22a7dafd46`。

## 失敗模式與驗收

An direct、PC-relative／immediate memory destination、非 word 記憶體型、其他 shift／
rotate 與 bus backend error 必須回傳錯誤。不改控制協定、素材、存檔或權利邊界。
三份語料逐筆比較 state、RAM、clock、bus 與 exception frame；既有 122,500 筆不得
回歸。2026-09-05 驗收結果為 7,500／7,500 全數通過；全套外部單步語料累計
130,000 筆全數通過。
