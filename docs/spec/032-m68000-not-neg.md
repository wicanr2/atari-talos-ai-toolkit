# 032 — Motorola 68000 NOT／NEG

狀態：**CONFORMED**（2026-09-05）。

## 範圍與輸入

涵蓋 MC68000 的 `NOT.B/W/L <ea>` 與 `NEG.B/W/L <ea>`。驗收輸入為 spec 003
固定的 `SingleStepTests/m68000` commit
`64b253116a3de04aaac4346c43680960dc9b67e5`：`NOT.b/w/l.json.bin` 與
`NEG.b/w/l.json.bin` 各 2,500 筆，共 15,000 筆。

NEGX、NBCD、TAS 與後代 CPU 擴充不在本切片；不合法 EA 失敗即關閉。

## 證據與 typed 行為

- **已確認（平台規格）**：Motorola／NXP《M68000 Family Programmer's Reference
  Manual》；官方 PDF SHA-256 為
  `06e4864b78da0e815054cead9326b7ec9914661f240fd39a455f2061ff47c4e8`。
- NOT 對指定寬度逐位元反相，依結果設定 N／Z、清除 V／C、保留 X。
- NEG 計算 `0−operand`；依寬度更新 X／N／Z／V／C，非零 operand 產生 borrow，
  最小負值取負時設定 V。
- byte／word Dn 只覆寫對應低位；long 覆寫全部 32 位。
- 記憶體目的端只允許可修改 data EA，採 operand read → final program prefetch →
  operand write；long 先寫 low word、再寫 high word。EA、FC、alignment、side effect、
  clocks 與 vector-3 frame 必須逐筆符合固定語料。
- **已確認（DM 使用範圍）**：DM12EN 產生組語中 NOT.W 54 次、NOT.L 2 次；
  NEG.W 28 次、NEG.L 6 次，合計 90 個靜態使用點。31 份 `.S` 雜湊清單 SHA-256 為
  `607feb2bc104af411d13e9909d9c57ffff626c3ef8737ec5cd765b22a7dafd46`。

## 失敗模式與驗收

An direct、PC-relative／immediate destination、NEGX、NBCD、TAS、未實作 opcode 與 bus
backend error 必須回傳錯誤。不改 JSONL 控制協定、Atari 素材、存檔或權利邊界。
六份語料逐筆比較完整 state、RAM、clock、bus 與 exception frame；既有 135,000 筆
不得回歸。2026-09-05 驗收結果為 15,000／15,000 全數通過；全套外部單步語料
累計 150,000 筆全數通過。
