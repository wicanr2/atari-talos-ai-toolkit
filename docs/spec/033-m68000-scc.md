# 033 — Motorola 68000 Scc

狀態：**CONFORMED**（2026-09-05）。

## 範圍與輸入

涵蓋 MC68000 全部 16 種 `Scc.B <ea>`：ST、SF、SHI、SLS、SCC、SCS、SNE、SEQ、
SVC、SVS、SPL、SMI、SGE、SLT、SGT、SLE。驗收輸入為 spec 003 固定的
`SingleStepTests/m68000` commit `64b253116a3de04aaac4346c43680960dc9b67e5`：
`Scc.json.bin` 共 2,500 筆。

DBcc、TRAPcc 與後代 CPU 擴充不在本切片；不合法 EA 失敗即關閉。

## 證據與 typed 行為

- **已確認（平台規格）**：Motorola／NXP《M68000 Family Programmer's Reference
  Manual》；官方 PDF SHA-256 為
  `06e4864b78da0e815054cead9326b7ec9914661f240fd39a455f2061ff47c4e8`。
- 依 opcode condition 與目前 N／Z／V／C 判定：成立寫 `0xff`，不成立寫 `0x00`；
  SR 全部位元不變。
- Dn 只覆寫最低 byte；條件成立與不成立在 MC68000 上有不同暫存器 clocks。
- 記憶體目的端只允許可修改 data EA；operand read、program prefetch、byte write、
  UDS／LDS、A7 byte delta、EA side effect 與 clocks 必須逐筆符合固定語料。
- **已確認（DM 使用範圍）**：DM12EN 產生組語中 Scc 族合計 244 個靜態使用點，
  其中 SEQ 142、SNE 54；31 份 `.S` 雜湊清單 SHA-256 為
  `607feb2bc104af411d13e9909d9c57ffff626c3ef8737ec5cd765b22a7dafd46`。

## 失敗模式與驗收

An direct、PC-relative／immediate destination、DBcc、TRAPcc、未實作 opcode 與 bus
backend error 必須回傳錯誤。不改 JSONL 控制協定、Atari 素材、存檔或權利邊界。
固定語料逐筆比較完整 state、RAM、clock 與 bus；既有 150,000 筆不得回歸。
2026-09-05 驗收結果為 2,500／2,500 全數通過；全套外部單步語料累計
152,500 筆全數通過。
