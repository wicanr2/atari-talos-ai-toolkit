# 040 — Motorola 68000 EOR／EORI

狀態：**CONFORMED**（2026-09-05）。

## 範圍與證據

本規格涵蓋 `EOR.B/W/L Dn,<data alterable EA>` 與
`EORI.B/W/L #imm,<data alterable EA>`。`EORI to CCR` 與 `EORI to SR` 有獨立語料，
但不屬於本切片；後者另涉及 supervisor 權限，不在這裡猜補。

固定外部語料來自 `SingleStepTests/m68000` commit
`64b253116a3de04aaac4346c43680960dc9b67e5`：

| 語料 | 分母與分類 | SHA-256 |
|---|---:|---|
| `EOR.b.json.bin` | 2,500；EOR 2,233、EORI 267 | `87bef8de9bb884665e411dd59a501aa2c10348cbe71127c332a139228df20250` |
| `EOR.w.json.bin` | 2,500；EOR 2,237、EORI 263 | `065fdad8329184f0154e04a1b678df32eb62a260f46ae487c2f854dcd28cce9f` |
| `EOR.l.json.bin` | 2,500；EOR 2,238、EORI 262 | `5de170b5c84f7a85f05936651fdb7b8653b5aa5b26360aaad525f94aed9a0373` |

DM12EN 重建組語集合雜湊見 spec 037；靜態盤點為 EOR／EORI 共 35 個使用點，
包含資料暫存器目的地、記憶體目的地與立即數形式。此計數只用於實作優先序，
不等同執行期頻率；反組譯清單中看似以 address register 為目的地的列不作合法 opcode 證據。

## typed 行為

1. 結果為 destination XOR source；byte／word 對 Dn 只更新低 8／16 bits，long 更新全部 32 bits。
2. X 保留；N／Z 依截斷後結果設定，V／C 清除。
3. EOR 的 source 固定為 Dn，destination 可為 Dn 或可修改記憶體 EA；EORI 先從指令流讀立即數。
4. 記憶體目的地採 read-modify-write：解析 EA、讀 operand、更新旗標、預取、再寫回。
   long 寫回維持 low word first；postincrement／predecrement 與 A7 byte delta 沿用既有 EA 契約。
5. word／long 奇數目的地進 vector 3；例外 frame、fault PC、bus 次序與 clocks 沿用
   spec 007 及外部語料逐筆結果。

## 驗收與停止線

- 三份語料合計 7,500 筆，逐筆比較完整 CPU state、RAM、clock 與非 idle bus transaction。
- `EORI to CCR`、`EORI to SR`、68010+ 行為與 backend bus fault 的 double-fault／halt
  不在本規格；待獨立 READY 規格後才能實作。
