# 042 — Motorola 68000 ROR

狀態：**CONFORMED**（2026-09-05）。

## 範圍與輸入

涵蓋 MC68000 暫存器型 `ROR.B/W/L #<count>,Dn`、`ROR.B/W/L Dn,Dn`，以及
固定一位的記憶體型 `ROR.W <ea>`。驗收輸入為 spec 003 固定的
`SingleStepTests/m68000` commit `64b253116a3de04aaac4346c43680960dc9b67e5`：

| 語料 | 分母 | SHA-256 |
|---|---:|---|
| `ROR.b.json.bin` | 2,500 | `aabe4dfd9ff678450b75687cfb158396e4ea400eedeec527ce5af154c2e46bee` |
| `ROR.w.json.bin` | 2,500 | `0e21a5bd6710b7292344fc8a628461f47909117e2d02d9143868ec5b27cb96ad` |
| `ROR.l.json.bin` | 2,500 | `425585edcbbd9ff8af771f2cb64e4fa88da6f2060284c30e0a7b8062efd4b2ed` |

ROXR、ROL、shift 與後代 CPU 擴充不在本規格；不合法 EA 失敗即關閉。

## 證據與 typed 行為

- **已確認（平台規格）**：Motorola／NXP《M68000 Family Programmer's Reference
  Manual》；官方 PDF SHA-256 為
  `06e4864b78da0e815054cead9326b7ec9914661f240fd39a455f2061ff47c4e8`。
- 暫存器 count 來自三位立即值（0 代表 8）或來源 Dn 低六位；記憶體型固定 word
  且只旋轉一位。
- 每次右旋將最低位送回該寬度的最高位並送入 C；count 為零時 C 清除。X 永遠保留，
  結果設定 N／Z，V 固定清除。
- 暫存器 byte／word 只覆寫 Dn 對應低位；clock 隨實際 count 增加。
- 記憶體型採 word read → final program prefetch → word write；alignment、FC、EA
  side effect 與 vector-3 frame 必須逐筆符合固定語料。
- **已確認（DM 使用範圍）**：DM12EN 產生組語中 ROR 有 10 個靜態使用點，包含
  Dn count、immediate count 與 word／long。此數量只用於實作優先序。

## 失敗模式與驗收

An direct、PC-relative／immediate memory destination、非 word 記憶體型、ROXR／ROL、
未實作 opcode 與 bus backend error 必須回傳錯誤。不改控制協定、素材、存檔或權利邊界。
三份語料逐筆比較 state、RAM、clock、bus 與 exception frame；既有 192,500 筆不得回歸。
2026-09-05 驗收結果為 7,500／7,500 全數通過；全套外部單步語料累計
200,000 筆全數通過。
