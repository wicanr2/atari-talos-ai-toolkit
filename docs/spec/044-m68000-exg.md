# 044 — Motorola 68000 EXG

狀態：**CONFORMED**（2026-09-05）。

## 範圍與證據

本規格涵蓋 MC68000 的 `EXG Dn,Dn`、`EXG An,An` 與 `EXG Dn,An` 三種合法 long
register exchange。驗收輸入為 spec 003 固定的 `SingleStepTests/m68000` commit
`64b253116a3de04aaac4346c43680960dc9b67e5`：

| 語料 | 分母與分類 | SHA-256 |
|---|---:|---|
| `EXG.json.bin` | 2,500；Dn↔Dn 834、An↔An 828、Dn↔An 838 | `6d1990dc8615dd2e0cb7193255e537827902f863ba09414c5e6091287b41de87` |

DM12EN 重建組語集合雜湊見 spec 037；靜態盤點為 6 個使用點，全部是 Dn↔Dn，
位於 `GROUP2.S`。此數量只用於實作優先序。

## typed 行為

1. 交換兩個指定暫存器的完整 32 bits；同一暫存器與自身交換時結果不變。
2. address register 透過目前 S bit 選擇的 register bank 讀寫，因此 A7 在 user mode
   指 USP、supervisor mode 指 SSP；未選中的另一個 stack pointer 不變。
3. EXG 不修改 SR、記憶體或控制流；完成 sequential prefetch，固定 6 clocks。
4. 三個合法 opcode pattern 必須先於同在 `0xCxxx` 空間的 AND 解碼，避免被較寬的
   AND opmode 判定誤路由。

## 失敗模式與驗收

其他 `0xCxxx` 編碼、未實作 opcode 與 backend bus fault 必須回傳錯誤；不改控制協定、
素材、存檔或權利邊界。固定語料 2,500 筆逐筆比較完整 state、RAM、clock 與非 idle
bus transaction；既有 210,000 筆不得回歸。
2026-09-05 驗收結果為 2,500／2,500 全數通過；全套外部單步語料累計
212,500 筆全數通過。
