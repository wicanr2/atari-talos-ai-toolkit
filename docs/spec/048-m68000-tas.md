## 範圍與證據

- Motorola／NXP《M68000 Family Programmer's Reference Manual》：TAS 先依原 operand
  設 N／Z、清 V／C、保留 X，再將 operand bit 7 設為 1。

## typed 行為

1. 合法目的為 Dn、mode 2–6 與 absolute word／long；An direct、PC-relative、immediate
   及其他 mode 7 編碼失敗即關閉。
2. Dn 只修改低 byte，固定 4 clocks；memory 以 byte EA 讀舊值、保留既有 A7 byte
   delta 與 postincrement／predecrement side effect。
3. 旗標由舊值決定：X 保留，N/Z 依 byte 設定，V/C 清除。之後將 bit 7 設為 1。
4. memory 順序為 operand read、operand write、順序 prefetch；基礎
   12 clocks 加既有 byte memory EA cost，因此 `(An)` 為 16 clocks。
5. Talos 現有 transaction 契約不保存 idle phase；特殊 RMW 的額外 2 clocks 計入總值，
   不冒稱已模擬 AS／UDS／LDS pin-level 的 5-cycle 波形。

## 排除範圍與驗收

- pin-level 5-cycle RMW 波形、外部 bus arbitration、backend bus fault 與 double fault
  不在本切片；當 ST bus arbitration 接入時需另立規格，不得回推本規格已涵蓋。
- Dn 392 筆必須原樣逐筆全同；memory 2,108 筆在套用上述已證實 `+2 clocks` 勘誤後，
  CPU state、RAM、clocks 與 transaction 全同。
- 全專案測試、`go vet -stdmethods=false` 與 CLI build 必須通過。

結果：2,500／2,500 筆在明示的 Hatari timing 勘誤後全同；全專案測試、vet 與
build 亦通過。CPU 外部單步驗收累計 227,500 筆。
