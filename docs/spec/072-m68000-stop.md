# 072 — MC68000 STOP

狀態：**CONFORMED**。

## 範圍與證據

本切片處理 MC68000 `STOP #<data>`（opcode `$4E72`）的 supervisor privilege、
16-bit immediate SR 載入、停止態與固定 EmuTOS 首次 STOP。interrupt／trace／external
reset 從停止態喚醒、interrupt acknowledge、完整 MFP IRQ 與 stopped machine 的畫格
推進均不在本切片。

- **已確認（Motorola／NXP 一手規格）**：NXP 官方《M68000 Family Programmer’s
  Reference Manual》，PDF SHA-256
  `06e4864b78da0e815054cead9326b7ec9914661f240fd39a455f2061ff47c4e8`，
  §6「STOP — Load Status Register and Stop」。只有執行前已在 supervisor state 才
  合法；否則 privilege violation。合法時 immediate data 載入完整 SR、PC 指向下一
  instruction，停止後不再 fetch／execute；trace、符合新 interrupt mask 的較高優先
  interrupt 或 external reset 才會恢復執行。
- **已確認（固定外部指令語料）**：SingleStepTests/m68000 commit
  `d7f92ecdec76c47071b598f53d270844490d097658bf6e7e982011abc866d975`，
  `STOP.json.bin` 共 2,500 筆。supervisor case 為 4 clocks、無 bus transaction，SR
  取 `immediate & $A71F`，既有 PC／prefetch 保留；user case 以執行前 SR 判權限，
  進 vector 8 privilege violation，34 clocks。語料 state schema 不含 processor
  stopped latch，因此另由 typed 測試補足。
- **已確認（固定 EmuTOS 1.3 與 Hatari opcode 定位）**：ROM SHA-256
  `ad64942f5b0f468a08b909827f6cfa2c38e786f853fab407011dc7d6f9c52135`。
  Talos 完成 7,598 條／178,092 clocks 後，依其 pipeline 契約 PC 指向下一指令
  `$FCD09E`，而目前 opcode 位於 `PC-4=$FCD09A`，預取為 `$4E72,$2300`。固定 ROM
  bytes 與 Hatari disassembly 同樣確認 `$FCD09A: STOP #$2300`；Hatari 在該點
  FrameCycles=`45752`、SR=`$2300`、prefetch=`$4E72,$2300`。規格 073 將 D2 修正為
  `$2710`；規格 075 後續接入第一個真實 VBL guest handler，使 D3 也由 `$466`
  讀得 `$1`。目前整機在第 7,604 條／178,228 clocks 進 STOP；本規格的 CPU
  transition 契約不變，舊的 7,599／178,096 收據由規格 075 取代。

## typed 行為

1. `STOP` 先以執行前 SR bit 13 判斷 supervisor；user mode 不讀取／套用 immediate，
   走既有 vector 8 standard exception，saved PC 指向 STOP opcode，34 clocks。
2. supervisor mode 將預取第二 word 視為 immediate，套用 MC68000 SR 有效位元 mask
   `$A71F`，再設定 CPU stopped latch；D/A、USP、SSP、PC 與 prefetch 不變，無 bus
   transaction，回報 4 clocks。
3. stopped latch 設定後再呼叫 `Step`／`StepAt`，回傳可辨識的 `ErrStopped`，0 clocks、
   無 transaction，CPU state 與 latch 均不變；不得把停止態模擬成忙迴圈。
4. CPU power-on `Reset()` 清除 stopped latch。interrupt／trace／external reset 喚醒
   尚無完整輸入契約，因此本切片不提供推測性喚醒入口。

## 驗收與停止線

- 2,500 筆 `STOP.json.bin` 全數通過，CPU 累計外部語料由 230,000 增至 232,500 筆。
- typed test 覆蓋 supervisor SR mask、stopped latch、重複 Step 原子失敗、Reset 清除，
  以及 user privilege exception 不進 stopped。
- 固定 EmuTOS 在接入規格 075 後應成功完成第 7,604 條／178,228 clocks，SR=`$2300`
  且 CPU stopped；下一次 Step 應回 `ErrStopped` 而不改 machine counters。
- 完整外部 corpus、固定 ROM、Go 測試、靜態檢查與建置均須通過，才可將狀態改為
  **CONFORMED**。接入規格 075 後固定 ROM gate 為第 7,604 條／178,228 clocks。

## 玩家路徑、存檔與權利邊界

此切片建立 CPU 停止態；規格 074／075 已補上第一 VBL 的中斷接受，但 recurring VBL
仍未完成，不代表 TOS 已完整開機。專案只保存官方手冊雜湊與導出的 typed 契約，不收錄手冊、ROM 或
外部語料。
