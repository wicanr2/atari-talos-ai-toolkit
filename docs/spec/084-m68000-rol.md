# 084 — Motorola 68000 ROL

狀態：**CONFORMED**。

## 範圍與輸入

涵蓋 MC68000 暫存器型 `ROL.B/W/L #<count>,Dn`、`ROL.B/W/L Dn,Dn`，以及
固定一位的記憶體型 `ROL.W <ea>`。驗收輸入為規格 003 固定的
`SingleStepTests/m68000` commit `64b253116a3de04aaac4346c43680960dc9b67e5`：

| 語料 | 分母 | SHA-256 |
|---|---:|---|
| `ROL.b.json.bin` | 2,500 | `58b6b13f627a6a23d6a19188bc8cb00934fb97bab5d00cee499d2d159984ea7b` |
| `ROL.w.json.bin` | 2,500 | `faa8775164afa38f336a8c73aaa651b4d00074bb5dd3b7f23b8c1cefaca9e01c` |
| `ROL.l.json.bin` | 2,500 | `fe5f2199fc91ec4883bdb8de7c75dc9414a5f231d079aabe17d85ab81e74e99d` |

ROXL、後代 CPU 擴充與 pin-level RMW 不在本規格；不合法 EA 失敗即關閉。

## 證據與 typed 行為

- **已確認（平台規格）**：Motorola／NXP《M68000 Family Programmer's Reference
  Manual》；官方 PDF SHA-256
  `06e4864b78da0e815054cead9326b7ec9914661f240fd39a455f2061ff47c4e8`。
- 暫存器 count 來自三位立即值（0 代表 8）或來源 Dn 低六位；記憶體型固定 word
  且只旋轉一位。
- 每次左旋將最高位送回該寬度最低位並送入 C；count 為零時 C 清除。X 永遠保留，
  結果設定 N／Z，V 固定清除。
- 暫存器 byte／word 只覆寫 Dn 對應低位；clock 隨實際 count 增加。
- 記憶體型採 word read → final program prefetch → word write；alignment、FC、EA
  side effect、bus fault 與 vector-3 frame 必須逐筆符合固定語料。
- **已確認（固定 EmuTOS 路徑）**：Timer C 啟動後的下一個 opcode 是
  `$FC6192: E378 1238`，即 `ROL.W $1238.W`；執行前 pipeline PC=`$FC6196`。

## 驗收與停止線

An direct、PC-relative／immediate memory destination、非 word 記憶體型、ROXL、
未實作 opcode 與 bus backend error 必須回傳錯誤。不改控制協定、素材、存檔或
權利邊界。三份語料逐筆比較 state、RAM、clock、bus 與 exception frame；既有
232,500 筆不得回歸。三份 ROL 語料實測 7,500／7,500 通過，累計 240,000 筆。
固定 EmuTOS 的 `$E378` 以 16 clocks 執行成功，之後前進到 68,131 instructions、
3 interrupts、963,388 clocks；下一 gate 是 `$FFFA09` IERB 非零寫入，完整 state
為 SSP=`$0F7E`、SR=`$2700`、pipeline PC=`$FC61F0`、prefetch=`$FA09,$1238`。
全測試、vet 與 build 通過後，本規格升 **CONFORMED**。
