# 134 — UCSD p-System IV.2.1 直譯器的真實程式碼執行

狀態：**CONFORMED**。

## 範圍與證據

本切片用 1985 年出貨的真實 68000 程式碼驗收 CPU 核心：SunDog: Frozen Legacy（Atari ST）
磁碟上的 `SYSTEM.INTERP`，也就是 UCSD p-System IV.2.1 的 p-machine 直譯器。

它與 `TALOS_M68000_TESTS` 的合成語料互補。合成語料逐條窮舉單一指令的狀態空間；這裡跑的
是一段有目的的程式：opcode 分派表、短常數、區域變數載入與陣列索引，指令彼此有真實的
資料相依。合成語料證明每條指令單獨正確，這裡證明它們串起來仍然做對事情。

- **素材**：`SYSTEM.INTERP`，11,776 bytes，SHA-256
  `a344edfb07d27cafa3dfda68f1854a76f63a0e89cf2e8229dacf5aa64d603c38`。
  原版磁碟檔案，**不進 repository**；測試以 `TALOS_UCSD_INTERP` 指向存放目錄，
  雜湊在測試裡釘死，換一份檔案就失敗。
- **為什麼現在就跑得動**：被驗收的這幾支常式在執行時只碰測試明確映射的記憶體。
  這一點由測試本身保證而不是靠掃描——`SparseMemory` 對未映射位址回傳錯誤，
  任何非預期的取值、trap 向量讀取或 I/O 存取都會讓測試失敗。因此本切片只需要
  MC68000 與記憶體，不依賴 Shifter、FDC、MFP 或任何尚未實作的周邊。
- **`SYSTEM.INTERP` 整體並非完全不含 trap**：偏移 `$008A` 有一條 `TRAP #15`，
  前面是 `move.w -16(pc),d0` / `beq.s`——旗標為零時跳過的除錯 hook。它不在本切片
  執行的路徑上。全檔沒有 `TRAP #1`／`#13`／`#14`，所以直譯器不呼叫 GEMDOS、BIOS
  或 XBIOS。（純位元組掃描還會在 `$14CE`、`$151C` 各報一次，那兩處實際上是字串
  `"FUNCTION"` 與 `"NOT "` 的內容，不是指令——位元組序列不等於程式碼。）
- **常式語意的來源**：SunDog remake 專案對 dispatch 表與各常式的人工反組譯
  （`docs/atari-st/` 與 `sundog-opcodes-decoded.md`）。**本規格不驗證那份解讀本身正確，
  驗證的是 Atari Talos 執行同一段位元組所得的結果與該解讀一致。** 兩邊獨立錯成同樣的
  結果才會假通過，而分派表的結構檢查不經過 CPU，可以擋掉這種情形。

## typed 行為

1. **分派表**（偏移 `$00EC`）是 256 項 big-endian word。opcode `$00`–`$1F` 全部指向
   `$00D8`，`$20` 指向 `$0534`。這一條純讀資料，不執行指令。
2. **短常數常式**（`$00D8`，p-code 的 `sldc0`–`sldc31`）：進入時 `D0` 是 opcode×2，
   常式為 `lsr.w #1,d0` / `move.w d0,-(sp)` / `jmp (a5)`，三條指令把常數推上運算元堆疊。
3. **區域變數載入**（`$0534`，opcode `$20`–`$2F` 對到區域變數 1–16）：
   `subi.w #$3E,d0` / `move.w 8(a0,d0.l),-(sp)` / `jmp (a5)`。減去 `$3E` 之後 `D0` 是
   「變數編號×2」，加上活動記錄標頭的 8 個位元組——這就是 p-system 活動記錄
   「編號 × 2 + 8」那條換算的出處。
4. **陣列索引**（`$0952`，p-code 的 `ixa n`）：先以 UCSD 變長編碼從 `(a4)+` 取元素大小
   （第一個位元組小於 `$80` 就是值本身，否則去掉最高位再吃一個位元組接在低位），
   pop 索引，索引非零時乘上元素大小再乘 2，加到堆疊上的基底。
   結果是 `base + index × n × 2`，且**基底是 byte 位址**——常式把位移直接加上去，沒有再乘。
5. 常式一律以 `jmp (a5)` 回到分派迴圈。測試把 `a5` 指向哨兵位址，執行到那裡即停。

## 驗收與停止線

- 直譯器映像載入位址由測試選定（非零基底）。這些切片不含 PC-relative 或絕對位址依賴；
  若某一天發現有，測試會失敗而不是碰巧通過。
- 每條斷言都做過負對照：期望值差 1、指令數差 1、活動記錄偏移差 2，都確認會讓測試失敗。
- **本切片不宣稱 Atari Talos 能執行 SunDog 或任何 p-system 程式。** 它只證明這幾支
  不碰硬體的常式在 CPU 上跑出正確結果。完整的 p-machine 需要磁碟載入、螢幕與輸入，
  屬於 M3；`SYSTEM.PASCAL` 的其餘部分不在這裡。分派迴圈本體與 p-code 序列執行由
  [規格 135](135-ucsd-psystem-dispatch-loop.md) 接手。
- 直譯器的其他常式（浮點、字串、集合、堆積、段落載入）尚未納入。
- 本切片不宣稱整份 `SYSTEM.INTERP` 都不碰硬體，只宣稱被驗收的這幾支常式在執行時
  沒有碰測試映射範圍以外的任何位址。
- 本切片不新增任何硬體行為，因此不需要硬體規格；它是驗收語料的契約。
