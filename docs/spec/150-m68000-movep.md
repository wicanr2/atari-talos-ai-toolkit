# 150 — MC68000 MOVEP

狀態：**READY**

已確認（Motorola 原廠手冊）：MOVEP 在 Dn 與 d16(An) 間傳送 word／long，
由高 byte 開始，每個記憶體 byte 的位址間隔 2；CCR 不變。
<https://www.nxp.com/docs/en/reference-manual/M68000PRM.pdf>，MOVEP 章節 4-131。
<https://www.nxp.com/docs/en/reference-manual/MC68000UM.pdf>，指令時序表。

- `MOVEP.l.json.bin` SHA-256 `3af21c3ebb5fb4c142df3c2dbce25a5fb651c4a804d3691ca3f3a06c6365b16a`。
- 已讀取兩種寬度／方向的初始與最終 state、完整 transaction。
  順序為一筆 program prefetch、2／4 筆 data byte、最後一筆 program prefetch；
  每筆 4 clocks，共 16／24。user/supervisor FC 分別 1/5、2/6。

契約：`opcode & 0xF138 == 0x0108` 必須先於 dynamic bit 解碼；bit 7
決定 register→memory，bit 6 決定 long。signed d16 加 An（含 active A7）
後做 24-bit bus masking；word load 保留 Dn 高 16 位。保持 SR／An。
TimedBus 必須在每次 access 前收到 epoch+累積 clocks，wait 推移後續 phase。
bus fault 暫採既有失敗即關閉，未聲稱完整 MOVEP vector-2 部分提交語意。

驗收：兩份完整語料各 2500 筆，state、RAM、clocks 與 bus 全符；
另驗 timed wait 傳播。正常 Automation 097 解壓選單的 `$0108` 不再被誤判。
